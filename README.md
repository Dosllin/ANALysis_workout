# 🦍 WORKOUT ANALYTICS CLI (Анализатор твоих банок)

> *Программа, которая поднимает гигабайты данных, пока ты поднимаешь железо 💪*

Устал записывать свои подходы в потный блокнот? Не знаешь, почему бицепс не растет, а на приседе трясутся колени? **Workout Analytics** - это консольная утилита на Python, которая прожует твой CSV-файл с тренировками и выдаст суровую правду о твоем прогрессе

---

## 🏆 Как мы закрыли ТЗ (Flexing our code muscles)

Этот проект написан настолько сурово, что его код сам ходит в качалку по выходным. Все требования преподавателя выполнены и перевыполнены:

- 🐼 **Pandas (Работа с базой):** `groupby`, `agg`, `mean`, `sum` — группируем данные жестче, чем ты сводишь лопатки на жиме
- 🔢 **Numpy (Математика):** Рассчитываем стандартное отклонение (`std`) и медиану весов. Вычисляем, стабильно ли ты прогрессируешь, или твои веса скачут, как настроение на сушке
- 🔄 **Генераторы (2+):** Ищем отказные тренировки через `yield`, потому что хранить всё в памяти (списках) — это как делать кардио: сжигает лишнее
- 🎀 **Декораторы (2+):** 
  - `@format_output` — оборачивает текст в красивые рамки, как бинты на колени перед тяжелым приседом.
  - `@log_action` — Запоминаем наши действия
- 💻 **CLI-интерфейс:** Интерактивное меню + мощный `argparse`. Программа управляется из терминала, мышки для слабаков
- 🧪 **Тесты (Pytest):** Покрыто тестами с использованием фикстур. Наш код защищен от багов лучше, чем твоя поясница штангистским поясом
- 📈 **Визуализация (Matplotlib):** Рисуем красивые графики прогресса, чтобы можно было хвастаться маме

## 🚀 Как затащить это к себе на ПК

Для начала убедись, что у тебя установлен Python (и выпит креатин)

**1. Клонируем репозиторий:**
```bash
git clone https://github.com/Dosllin/ANALysis_workout.git
cd ANALysis_workout
```

**2. Закидываем протеин (устанавливаем зависимости):**
```bash
pip install -r requirements.txt
```

**3. Жмем кнопку старта:**
```bash
python main.py
```

## 🕹 Управление из терминала (CLI)

Мы встроили `argparse`. Ты можешь дергать скрипт прямо из консоли без захода в меню:

- `python main.py add` — Быстро записать тренировку (пока не остыли мышцы)
- `python main.py analyze` — Открыть меню аналитики
- `python main.py stats` — Вывести быструю сводку: самый жесткий день и стабильность весов
- `python main.py report` — 💥 ГЕНЕРАЦИЯ ПОЛНОГО ОТЧЕТА 💥. Выводит всю статистику махом
- `python main.py -h` — Вызвать помощь

## 🧠 Что умеет эта шайтан-машина? (Аналитика)

Проект делает **6 осмысленных выводов** (вместо требуемых 5):

1. 🏋️ **Прогресс в упражнении:** Считает, сколько кг ты накинул на штангу за выбранный период
2. ⚖️ **Детектор "Подснежника":** Сравнивает тренировки разных мышечных групп. Анализатор сразу спалит, если ты тренируешь только бицепс и пропускаешь день ног
3. 🏆 **Месяц-рекордсмен:** Вычисляет месяц с максимальным поднятым тоннажем (перемножаем Вес × Сеты × Повторения)
4. 🔥 **Влияние тяжести (RPE):** Анализирует твой уровень страдания на тренировках. Выясняем, где тяжелее: на приседе или на сгибаниях рук
5. 🦍 **Поиск пикового дня:** Находит самую хардкорную тренировочную сессию в твоей жизни
6. 📉 **Анализ стабильности (Numpy):** Считает разброс весов. Если разброс большой - программа порекомендует проверить технику или режим сна
